# 블루베리 밸리

캐릭터를 직접 움직여 블루베리를 심고 수확하고, 마을 상점과 판매대를 오가며 농장을 키우는 탑다운 Pygame 농장 게임입니다.

맵 가장자리에는 추가로 걸어 다닐 수 있는 잔디 여백이 있으며, 카메라도 이 여백까지 이동합니다. 북쪽 나무 가까이 가도 수관과 상호작용 표시가 상단 정보창 뒤에 가려지지 않습니다.

## 실행

macOS에서는 `run.command`를 더블클릭하세요. macOS가 처음 실행을 막으면 파일을 우클릭하고 **열기**를 선택합니다.

VS Code 터미널에서는 다음처럼 실행합니다.

```bash
cd /Users/choijiwon/Desktop/s0uyyn
python3 -m pip install -r requirements.txt
python3 main.py
```

## 조작법

- `WASD` 또는 방향키: 캐릭터 이동
- `E` 또는 `Space`: 가까운 밭·건물·판매대와 상호작용
- 가로등 부지 앞에서 `E`: 3,000코인으로 가로등 설치
- `B`: 4×4 재료 가방 열기/닫기
- `H`: 도움말
- `M`: 배경음악 켜기/끄기
- 시설 관리 화면에서 `E`: 건설 또는 생산품 받기
- 시설 관리 화면에서 `U`: 시설 업그레이드
- `Ctrl/⌘+S`: 저장
- `ESC`: 메뉴 닫기 또는 게임 종료
- 상점 안에서 `1`~`4`: 씨앗, 꿀, 우유, 얼음 구매
- 생과 시장 안에서 `1`: 일반 블루베리, `2`: 황금 블루베리 판매
- 블렌더 안에서 `+ / -` 클릭: 각 재료를 직접 추가하거나 빼기
- 블렌더 안에서 `1`~`4`: 재료 추가, `Shift+1`~`Shift+4`: 재료 빼기, `Enter`: 완성
- 블렌더 안에서 `5`: 고급 꿀, `6`: 저지방 우유 넣기/빼기

## 농장 운영 순서

1. 밭으로 걸어가 빈 밭 가까이에서 `E`를 눌러 씨앗을 심습니다.
2. 다 익은 블루베리 나무 가까이에서 `E`를 눌러 블루베리 4개를 직접 수확합니다. 마을의 큰 나무도 가까이에서 `E`를 누르면 흔들 수 있습니다.
3. 카트 앞 맨 앞 손님의 말풍선에서 이름, 단골·VIP 여부, 만족도와 주문을 확인합니다. 블루베리는 항상 3개이며 우유는 1~2개, 얼음은 1~3개 중에서 무작위로 정해집니다. 봄·여름·가을의 꿀 주문은 `없음 15% · 1개 55% · 2개 30%`로, 대부분의 레시피에 꿀이 들어갑니다. 여름과 무더운 날에는 얼음 주문이 많아지고, 겨울에는 꿀이 반드시 1~2개 들어갑니다.
4. 동쪽 초록 지붕 상점에서 주문에 필요한 꿀·우유·얼음을 삽니다. 보라색 블렌더 앞에서 `E`를 누르면 직접 제조 화면이 열립니다. 각 재료의 `+ / -`를 눌러 주문 수량과 똑같이 맞춘 뒤 **스무디 완성**을 누릅니다. 배합이 맞으면 믹서가 재료를 가는 장면이 3초 동안 재생된 다음 스무디가 완성됩니다. 틀린 배합은 재료를 소비하지 않고 무엇을 더 넣거나 빼야 하는지 알려 줍니다.
5. 남쪽 생과 시장에서 일반 또는 황금 블루베리를 골라 팔거나, 남동쪽 카트 앞에 줄 선 손님에게 주문 스무디를 직접 팝니다. 스무디 판매가는 기존보다 20% 인상되었으며, 재료가 많이 들어가거나 만족도가 높을수록 가격과 팁이 더 올라갑니다. 고급 꿀·저지방 우유 보너스는 인상된 가격에 각각 100코인씩 추가됩니다. 한 잔을 팔 때마다 맨 앞 손님이 인사하며 떠나고, 새 손님은 일정 시간이 지나면 서로 다른 주문과 대사를 가지고 줄 끝에 합류합니다.
6. 농장 오른쪽의 확장 간판에서 새 텃밭을 구입합니다. 첫 땅은 10,000코인이며 한 칸 살 때마다 다음 가격이 2,500코인씩 올라갑니다(10,000 → 12,500 → 15,000…). 간판에는 현재 구입할 다음 땅의 가격이 표시됩니다.
7. 농장집·블루베리 밭·벌통과 생산시설·상점·생과 시장·스무디 판매대에 나누어 배치된 가로등 부지에서 `E`를 누르면 가로등을 한 개당 3,000코인에 설치할 수 있습니다. 설치한 가로등은 저녁부터 새벽까지 자동으로 켜집니다.

`B`를 누르면 4×4, 총 16칸인 재료 가방이 열립니다. 블루베리·씨앗·꿀·우유·얼음과 나무에서 찾은 희귀 아이템은 같은 종류끼리 한 칸에 최대 16개가 쌓이고, 16개를 넘으면 다음 칸을 사용합니다. 완성된 스무디는 가방 칸을 차지하지 않습니다. 가방이 꽉 차면 새 재료를 사거나 블루베리를 수확할 수 없으며, 재료를 사용하거나 블루베리를 판매해 칸을 비울 수 있습니다. 기존 저장 파일의 재료 개수는 그대로 유지됩니다.

## 새 진행 콘텐츠

### 낮과 밤, 가로등

하루 24분 동안 게임 시각도 06:00부터 다음 날 06:00까지 24시간이 모두 흐릅니다. 실제 플레이 1분이 게임 속 1시간이며 `아침 06~08시 · 낮 08~18시 · 저녁 18~20시 · 밤 20~04시 · 새벽 04~06시`로 나뉩니다. 날짜는 다음 날 06:00에 바뀌고 상단 시계에도 현재 시간대가 표시됩니다.

마인크래프트의 연속적인 천체 주기를 참고해, 직접 만든 픽셀 해가 동쪽에서 떠서 낮 동안 화면 위를 곡선으로 이동한 뒤 서쪽으로 집니다. 해가 지면 픽셀 달과 별이 같은 경로를 이어서 움직이고 날짜에 따라 달 모양도 달라집니다. 일출·낮·노을·한밤중·새벽 사이의 화면색은 갑자기 전환되지 않고 부드럽게 변합니다. 참고한 구조는 Minecraft 공식 문서의 `sun_angle`, `moon_angle`, `star_brightness` 설명이며 이미지나 텍스처는 복사하지 않았습니다.

맵에는 가로등 설치 부지가 총 6곳 있으며 농장집, 블루베리 밭, 벌통과 생산시설, 상점, 생과 시장, 스무디 판매대에 한 곳씩 고르게 분산되어 있습니다. 각 가로등은 3,000코인이며, 설치하면 어두운 시간에 주변에 따뜻한 원형 빛을 만들기 때문에 밤길과 상호작용 지점을 더 쉽게 볼 수 있습니다. 설치 여부와 사용한 비용은 `save_game.json`에 자동 저장되며, 이전의 3개 가로등 설치 기록도 그대로 이어집니다.

### 나무 흔들기와 희귀 아이템

마을 곳곳의 큰 나무 가까이에서 `E`를 누르면 동물의 숲처럼 나무가 흔들리고 아이템이 하나 떨어집니다. 각 나무는 게임 날짜 기준 하루에 한 번만 보상을 주며 다음 날 다시 흔들 수 있습니다.

| 떨어지는 보상 | 확률 | 수량·효과 |
|---|---:|---|
| 블루베리 | 20% | 1~3개 |
| 꿀 | 20% | 1~3개 |
| 우유 | 20% | 1~3개 |
| 얼음 | 20% | 1~3개 |
| 코인 | 5% | 100~250코인 |
| 황금 블루베리 | 8% | 1개 · 생과 시장에서 200코인에 판매 |
| 고급 꿀 | 3% | 1개 · 스무디 판매가 +100코인 |
| 저지방 우유 | 3% | 1개 · 스무디 판매가 +100코인 |
| 씨앗 | 1% | 1개 |

기본 재료 네 종류를 합친 확률은 80%로 유지됩니다. 고급 꿀과 저지방 우유는 각각 3%로 낮추고 황금 블루베리는 8%로 높였으며, 남는 1%에서는 씨앗 1개가 나옵니다. 블렌더 화면에서 고급 꿀은 `5`, 저지방 우유는 `6`으로 선택하며 각각 한 개씩 소비합니다. 두 희귀 재료를 함께 넣으면 판매 금액이 총 200코인 추가되고, 믹서가 도는 동안 선택한 희귀 아이콘도 용기 안에 표시됩니다.

### 하루 목표와 정산

하루마다 `블루베리 수확`, `스무디 판매`, `판매 수입` 중 하나가 목표로 정해집니다. 화면 위쪽에서 진행도를 확인할 수 있고, 달성하면 정산 때 코인과 평판 보상을 받습니다. 날짜가 바뀌면 판매 수입, 사용한 돈, 순이익, 수확량, 스무디 판매량이 표시되며 `E`를 눌러 다음 날을 시작합니다.

### 생산 시설과 업그레이드

농장 남쪽에 있는 시설 부지 앞에서 `E`를 누르면 시설 관리 화면이 열립니다.

| 시설 | 해금 | 건설비 | 1/2/3단계 하루 생산량 |
|---|---:|---:|---:|
| 벌통 | 농장 등급 1 | 2,000코인 | 꿀 2/3/5개 |
| 제빙기 | 농장 등급 2 | 4,000코인 | 얼음 4/7/10개 |
| 젖소 축사 | 농장 등급 3 | 7,000코인 | 우유 2/4/6개 |

시설은 건설한 다음 날부터 생산품을 받을 수 있습니다. 업그레이드 가격도 벌통은 3,500→6,000코인, 제빙기는 7,000→11,000코인, 젖소 축사는 12,000→18,000코인으로 단계마다 상승합니다. 2단계와 3단계 업그레이드는 더 높은 농장 등급도 필요합니다. 생산품을 받을 가방 공간이 부족하면 시설에 그대로 보관됩니다.

### 평판, 단골과 VIP

손님 이름은 게임에 포함된 한국 성씨 20개와 이름 80개를 조합한 1,600개의 가상 한국 이름 중에서 정해지며, 같은 대기 줄 안에서는 이름이 겹치지 않습니다. 이름 데이터 구성은 MIT 라이선스의 [korean-name-generator](https://github.com/agemor/korean-name-generator)를 참고했습니다. 실제 인물의 개인정보 목록을 게임에 저장하지 않고 조합용 데이터만 로컬에서 사용합니다.

주문을 정확하게 판매하면 평판이 오르고 농장 등급이 최대 5까지 상승합니다. 손님은 기다리는 동안 만족도가 조금씩 내려가므로 빠르게 만들수록 팁과 평판을 더 받습니다. 한 번 방문한 손님은 35% 확률로 다시 찾아와 단골이 되며, 보라색 이름표·전용 대사·추가 팁과 평판 보상을 받습니다. 농장 등급 2부터 VIP가 등장하며 금색 이름표와 왕관, `유명 요리사`나 `축제 심사위원` 같은 직함이 표시됩니다. VIP 주문은 기본 가격이 1.5배이고 판매 시 더 많은 평판을 받습니다.

### 계절, 날씨와 블루베리 축제

한 계절은 7일이며 `봄 → 여름 → 가을 → 겨울` 순서로 반복됩니다. 비는 작물을 빠르게 키우고 수확량을 1개 늘리며, 가을에도 수확량이 1개 늘어납니다. 무더위에는 얼음 주문과 스무디 가격이 올라가고, 겨울에는 생과 블루베리 가격이 2코인 올라갑니다. 겨울 눈과 계절별 땅 색, 비·바람·무더위 효과도 화면에 표시됩니다.

여름 7일차는 블루베리 축제입니다. 모든 손님이 VIP가 되고 스무디 판매 금액이 2배가 됩니다. 축제 목표인 스무디 3잔을 판매하면 일반 목표보다 큰 코인·평판 보상을 받습니다.

스무디 판매가 성공할 때만 첨부 영상의 전체 오디오 트랙에서 추출한 소리가 한 잔당 정확히 한 번 재생됩니다. 시작 부분이 잘리지 않도록 원본의 앞쪽 여유 구간을 보존하고 그 앞에 무음 0.5초를 추가했습니다. 이 판매음 외에 별도의 효과음은 없습니다.

배경음악 `blueberry_morning.ogg`는 참고 링크의 실제 음악을 복사하지 않고 게임을 위해 새로 만든 포근하고 장난스러운 38.4초 루프곡입니다. 판매 효과음이 재생될 때는 배경음악이 자동으로 작아지고, 효과음이 끝나면 천천히 원래 볼륨으로 돌아옵니다.

진행 상황과 캐릭터 위치, 평판, 손님 방문 기록, 일일 집계, 시설 단계와 생산 날짜, 희귀 아이템 수량과 그날 흔든 나무는 `save_game.json`에 5초마다 자동 저장됩니다. 날짜는 누적 시간뿐 아니라 현재 날짜·하루 진행률·하루 길이도 함께 기록해 정확하게 복원합니다. 이전 12분 기준 저장 파일은 날짜와 당일 진행률을 유지한 채 새로운 24분 기준으로 자동 변환되므로 기존 농장을 그대로 이어서 사용할 수 있습니다.

게임 날짜는 실제 달력이 아니라 **게임을 직접 플레이한 시간**으로 계산됩니다. 한 게임 날짜는 실제 플레이 24분이며 오전 6시부터 오후 10시까지 흐릅니다. 게임을 종료해 둔 시간과 상점·도움말·블렌더·가방·시설·정산 화면을 보고 있는 동안에는 시간이 멈추므로, 다시 실행했을 때 날짜가 갑자기 뛰지 않습니다.

상점과 블렌더 화면에는 사용자가 제공한 이미지에서 분리한 우유·블루베리·얼음·꿀 픽셀 아이콘이 표시됩니다. 블루베리 생과 시장과 재료 가방에도 같은 블루베리 아이콘이 사용됩니다. 믹서가 작동하는 3초 동안에도 실제 주문에 넣은 개수만큼 같은 아이콘들이 용기 안에서 회전합니다.

주인공은 사용자가 제공한 사진 속 캐릭터를 바탕으로 만든 전용 스프라이트입니다. `assets/player_reference_sheet.png`에 앞·왼쪽·오른쪽·뒤 방향별 3개 프레임이 들어 있으며, 이동 방향에 맞춰 걷기 애니메이션이 재생됩니다. 이 이미지가 없거나 손상되면 게임이 멈추지 않고 코드로 그린 기본 캐릭터가 대신 표시됩니다.

## 디자인 참고

- [Clear Code PyDew](https://github.com/clear-code-projects/PyDew): 작은 원본 타일의 정수 배율 확대, 카메라, 깊이 레이어 구조를 참고했습니다. 저장소 설명상 코드는 CC0입니다.
- [Pydew Valley](https://github.com/artemn0va/pydew-valley): 작물 성장 단계, 지면·작물·파티클 레이어 구성과 상점 동선을 참고했습니다. MIT 라이선스 프로젝트입니다.

참고 프로젝트의 그래픽 파일이나 스타듀밸리 원본 이미지는 복사하지 않았습니다. 지면, 건물, 나무, 작물, 손님과 UI는 제한된 색상표를 사용해 Pygame 코드로 새로 그렸으며, 플레이어 스프라이트는 사용자가 제공한 캐릭터 사진을 바탕으로 새로 제작했습니다. macOS에서 투명 이미지가 네모로 변하지 않도록 월드와 스프라이트를 화면에 직접 그립니다.
