# 옆모습 후보

`side_candidates.png`에서 3가지 후보의 좌우 모습과 축소 후 게임 크기를 비교합니다.

1. 자연스러운 옆얼굴: 작은 입, 완만한 턱선, 슬림한 옆선.
2. 동글동글 인형형: 둥근 볼, 또렷한 눈, 짧은 턱.
3. 살짝 돌아본 ¾형: 기존 웃는 표정, 얼굴이 조금 더 보이는 각도.

각 `candidate_N_walk.png`는 96×120 프레임 12개씩, 왼쪽/오른쪽 2행으로 구성됩니다.
선택한 2번 동글동글 인형형을 `dressup.py`의 좌우 옆모습에 적용했습니다.
기본 캐릭터와 옷장 의상 모두 적용되며 머리띠·머리색·신발·양말 선택을 유지합니다.
두 차례 10%씩 축소한 크기(원래의 81%)와 키는 유지합니다.
방향 전환 시 체형 차이를 줄이기 위해 앞·뒷모습의 가로 폭은 10% 줄이고,
옆모습은 어깨·치마를 넓히고 전체 폭도 8% 늘렸습니다.
`balanced_proportions.png`에서 현재 4방향 비율을 비교할 수 있습니다.
`applied_candidate_2.png`는 실제 게임 렌더러로 만든 적용 미리보기입니다.
`python3 assets/generate_side_candidates.py`로 재생성합니다.
