# 블루벨리 옷장

집의 옷장 탭에서 1,500코인에 구입하고 꾸미기 모드로 배치합니다.
집에서 C 또는 옷장 열기 버튼을 누르거나 배치된 옷장을 클릭하면 열립니다.
의상 12종, 머리띠 7종(없음 포함), 신발 6종, 머리색 6종,
양말 6종(없음 포함)이 진열됩니다. 기본 캐릭터가 쓰는 상품과 머리띠·양말의
`없음`만 처음부터 보유하며, 나머지는 코인으로 구입한 뒤 자유롭게 다시 입습니다.

종류 탭 또는 1~5로 목록을 바꾸고 상품을 클릭해 착용합니다.
좌우 방향키로 걷기 미리보기 방향을 바꿀 수 있습니다.
블루베리 세트는 총 4,950코인, 고래 세트는 총 5,400코인입니다.
두 테마의 모든 부위는 각각 1,000코인 이상이며, 이미 산 부위 가격은 세트 구입가에서
자동으로 빠집니다. 세트 버튼은 부족한 부위를 함께 구입하고 바로 적용합니다.
머리색은 유지되며 부위별로 다시 조합할 수 있습니다.
착용 정보는 자동 저장됩니다. 처음 캐릭터로 되돌리기로 기존 원본 모습을 복원합니다.
옷장을 보관함에 넣어도 착용 중인 옷은 유지됩니다.

## 디자인 파일

- `catalogue_outfit.png`: 캐릭터 없이 12종 의상 상품만 전체 보기
- `catalogue_headband.png`, `catalogue_shoes.png`, `catalogue_hair.png`, `catalogue_socks.png`: 부위별 보기
- `outfit_*.png`: 투명 배경 4방향 × 3프레임 시트 (한 프레임 96×120)
- `walk_*.png`: 게임 크기에 맞춘 4방향 × 12프레임 걷기 시트 (한 프레임 86×108)
- 행 순서: 정면, 왼쪽, 오른쪽, 뒤 / 열 순서: 기본, 걷기 1, 걷기 2
- 옷장 가구 디자인: `../furniture/wardrobe.png`

기존 게임의 픽셀 외곽선, 긴 머리와 웃는 얼굴을 바탕으로 코드로 디자인했습니다.
게임은 `dressup.py`에서 부위를 합성하고 옷을 바꿀 때만 걷기 프레임을 생성합니다.
게임 옷장 오른쪽 상품 카드와 `catalogue_*.png`에는 캐릭터 없이 해당 제품만 표시됩니다.
왼쪽 거울과 `outfit_*.png`에는 착용한 캐릭터의 전체 모습이 표시됩니다.
이 폴더의 PNG는 같은 렌더러로 만든 디자인 확인·재사용용 출력물입니다.
PNG를 직접 편집하면 게임에 자동 반영되지는 않으며 렌더러를 수정해야 합니다.
`python3 assets/generate_wardrobe_assets.py`로 전체 PNG를 재생성할 수 있습니다.
종류, 이름, 테마 구성은 `wardrobe_catalog.py`에서 관리합니다.
